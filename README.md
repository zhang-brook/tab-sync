# Tab Sync

> 帮你把浏览器里散落、堆积成百上千的标签页整理得井井有条，还能在多台设备之间同步。

Tab Sync 是一款开源的浏览器扩展（支持 Chrome / Edge）。如果你经常同时打开几十上百个标签页、还分散在好几个窗口里，它能帮你：

- 在**侧边栏**里把所有标签页按「窗口 → 分组 → 标签页」整齐列出来，并随你浏览实时更新；
- 把常用的标签页整理进**「工作组」**长期收藏；
- 在**多台电脑 / 多个浏览器**之间保持同步（需连接后端）。

---

## ✨ 功能亮点

- **侧边栏总览，一目了然**
  点击工具栏图标即可打开侧边栏，以「窗口 → 分组 → 标签页」的树状结构展示当前浏览器打开的所有页面，并随你打开 / 关闭 / 移动标签页**实时更新**。

- **自动定位你正在看的标签**
  每次打开侧边栏，列表会自动滚动并高亮到你**当前正在浏览**的那个标签页；当你在浏览器里切换标签时，侧边栏的高亮也会**实时跟随**变化，再也不用在长列表里手动找。

- **搜索 + 窗口筛选**
  顶部搜索框可按标题或网址快速过滤；窗口下拉框可在「全部窗口 / 当前窗口 / 指定窗口」之间切换，窗口与分组都支持折叠展开。

- **多选批量整理到「工作组」**
  勾选多个标签页或整个分组，一键加入已有工作组或新建工作组（弹窗内带搜索的树状选择器），适合把一批相关页面成组保存。

- **在侧边栏直接操作标签页**
  悬停即可关闭某个标签页，无需回到浏览器窗口一个个点 ×。

- **工作组：升级版收藏夹（需连接后端）**
  把标签页保存到云端「工作组」中长期留存，支持层级目录、按创建时间查看、筛选、批量**打开全部 / 打开选中项**，也支持直接通过网址添加。
  管理面板左侧的工作组树可直接**拖拽调整层级与显示顺序**（拖动节点改变父级，或在同级间上下插空排序），排序结果保存在云端，多设备一致。

- **跨设备同步（需连接后端）**
  配合自带的轻量后端，可在多台电脑、多个浏览器之间同步标签页与工作组的变更，避免在不同设备重复打开同一批页面。

- **回收站：误删可恢复**
  从工作组里移除的标签页不会立刻消失，而是先进入「回收站」。你可以在管理面板里把它们恢复回「未分组」，或确认后彻底删除、一键清空，避免手误丢数据。

- **标签系统（需连接后端）**
  为工作组或组内标签页打上彩色标签，并在侧边栏 / 管理面板中按标签快速筛选；标签保存在云端后端、跨设备共享，方便对大量页面做分类管理。

- **快捷键「加入并关闭」（需连接后端）**
  在「设置」里指定一个「默认收藏工作组」后，按下 `Shift+Alt+S` 即可把当前正在看的标签页收藏进该工作组并自动关闭；若尚未设置默认工作组，则打开侧边栏引导你选择目标（是否启用该快捷键可在设置中开关）。

- **完整管理面板**
  独立的「管理面板」页面提供：标签页查看、工作组管理、已连接设备、以及连接与账号设置。

- **隐私友好**
  界面上会区分「来自本机浏览器」与「来自云端后端」的数据，让你清楚知道哪些信息只在本地、哪些会上传，避免隐私顾虑。

## 🚀 安装

> 本项目仍在持续完善中，尚未上架 Chrome / Edge 应用商店。目前需通过「开发者模式」加载本地构建的扩展（对项目结构无影响，纯前端加载）。

### 方式一：从源码构建（推荐）

```bash
# 进入扩展目录
cd browser-extension

# 安装依赖
npm install

# 生产构建（产物在 dist/ 目录）
npm run build
# 或开发模式（支持热更新）：npm run dev
```

然后：

1. 打开 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge）。
2. 右上角打开「**开发者模式**」。
3. 点击「**加载已解压的扩展程序**」，选择上一步生成的 `browser-extension/dist` 目录。
4. 工具栏出现 Tab Sync 图标，点击即可打开侧边栏。

### 方式二：等待应用商店上架

商店版本发布后，可直接在 Chrome Web Store / Edge Add-ons 中搜索「Tab Sync」一键安装，无需构建。

## 🛠 使用指南

### 1. 打开侧边栏

点击浏览器右上角的 Tab Sync 图标，侧边栏会立即打开并定位到你当前浏览的标签页。

### 2. 浏览与定位

- 侧边栏按「窗口 → 分组 → 标签页」分层展示，窗口与分组可点击折叠/展开。
- 高亮项始终对应你浏览器中**当前激活**的标签页，切换浏览器标签时自动同步。
- 用顶部**窗口下拉**只看某个窗口，或用**搜索框**按关键词过滤。

### 3. 整理到工作组

1. 勾选需要的标签页（可勾选单个、整组，或跨多个窗口批量勾选）。
2. 点击出现的「**加入工作组**」按钮。
3. 在弹窗中搜索并选择目标工作组，或新建一个，确认即可。

> 工作组保存在云端后端，需先在「设置」中连接后端（见下文）。未连接时仍可正常浏览和管理本机标签页。

### 4. 管理面板

点击侧边栏右上角「**管理面板**」打开完整后台页面，可在其中：

- **标签页**：分页、筛选查看当前打开的标签页（含分组）。
- **工作组**：创建 / 管理层级工作组、批量打开或关闭其中的页面、按网址添加；左侧工作组树可直接拖拽调整层级与顺序。
- **设备**：查看已连接的后端设备。
- **回收站**：找回误删的工作组标签页，支持恢复、彻底删除或一键清空。
- **标签**：集中管理彩色标签，给工作组和标签页分类。
- **设置**：连接模式、API Token、版本信息、清除本地数据等。

## 🌐 跨设备同步（可选）

侧边栏的标签页管理**完全在本地运行**，无需任何服务器。若希望多设备同步或长期使用「工作组」，可部署配套的后端：

1. 部署轻量后端（Go + Gin + SQLite，单文件 / Docker 均可）。
2. 首次启动后访问 `http://<服务地址>/setup` 完成初始化并生成 API Token。
3. 在扩展的「设置 → 连接模式」选择「**轻量后端**」，填入服务地址与 Token，点击验证。
4. 连接成功后，侧边栏的「加入工作组」等操作即会同步到云端，其他设备登录同一后端即可看到。

> 「织个网」云端模式目前在扩展中标记为「预留 / 暂未开放」。

## ❓ 常见问题（FAQ）

**Q：点击工具栏图标没反应 / 侧边栏打不开？**
A：请确认你使用的是 Chrome 或 Edge，且扩展已通过 `chrome://extensions` 以「开发者模式」正确加载（商店版发布后将无需此步骤）。若曾加载过旧版本，建议在扩展管理页「重新加载」一次。

**Q：侧边栏能正常看标签，但「加入工作组」没反应？**
A：工作组数据保存在云端后端。「加入工作组」前请先在「设置」中连接并验证轻量后端（见上文「跨设备同步」）。

**Q：我的标签页数据会被上传吗？会不会泄露隐私？**
A：不连接后端时，所有标签页管理都**只在你本机浏览器内**进行，不上传任何数据。连接后端后，仅你主动「加入工作组」的标签页会保存到该后端（通常是你自己的服务器）。界面上区分了「本机数据」与「云端数据」，便于你确认。

**Q：不小心把工作组里的标签页删了，能找回来吗？**
A：可以。从工作组移除的标签页会先进入「管理面板 → 回收站」，你可以在那里恢复回「未分组」，或确认后彻底删除、一键清空。

**Q：支持 Firefox 吗？**
A：当前扩展基于 Chrome Manifest V3，主要面向 Chrome / Edge。Firefox 的 MV3 兼容支持待评估。

**Q：可以只装后端、不装扩展吗？**
A：后端是给扩展提供同步能力的服务，单独运行没有图形界面意义；建议配合扩展一起使用。

## 🔒 隐私说明

- **本地优先**：标签页的浏览与管理默认全部在本地完成。
- **可控上传**：仅当你主动把标签页加入「工作组」并连接后端时，相关数据才会发送到你所配置的后端服务。
- **自建可控**：配套的轻量后端可部署在你自己的服务器 / NAS 上，数据完全由你掌控。
- 界面会明确标注数据来源（本机 / 云端），帮助你随时了解数据去向。
