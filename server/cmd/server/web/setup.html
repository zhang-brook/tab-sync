访问令牌

小贴士：如果你在多个浏览器上使用本扩展，建议为每个浏览器单独创建一个令牌，并以浏览器名称命名（例如「家里的 Firefox」「公司的 Edge」）。这样在令牌列表中一眼就能分辨每个令牌对应哪台设备。

仅用于标签同步的普通令牌无需勾选。此权限与后台登录密码无关——后台始终用管理员密码登录，令牌本身不能登录后台网页。

吊销该令牌？

令牌 — 被吊销后将立即失效，使用该令牌的扩展无法继续同步。此操作不可撤销。
