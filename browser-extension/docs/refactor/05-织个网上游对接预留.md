## 详细说明

### 5.1 增量同步数据结构

当前 `model.SyncEvent` 已定义：

```go
type SyncEvent struct {
    ID         uint   `gorm:"primaryKey;autoIncrement"`
    EventID    string `gorm:"uniqueIndex;size:64;not null"`
    EventType  string `gorm:"size:50;not null"`   // created / updated / removed
    EntityType string `gorm:"size:50;not null"`   // workspace / tab / device
    EntityID   string `gorm:"index;size:64"`
    Payload    string `gorm:"type:text"`            // JSON
    Version    int64  `gorm:"default:0"`            // 数据版本号
    SyncedAt   *time.Time                           // 已同步到上游的时间
    CreatedAt  time.Time
}
```

需要在各 Service 中，当数据发生变更时自动记录 SyncEvent：
- `WorkspaceService.Create/Update/Delete` → 写入 SyncEvent
- `DeviceService.Register/Deregister` → 写入 SyncEvent

## 边界情况考虑

| 场景 | 处理策略 |
|------|---------|
| 浏览器未打开 | SSE 消息排队，等待扩展连接后处理 |
| 网络断开 | SyncEvent 本地暂存，恢复后批量重推 |
| 上游不可达 | 指数退避重试，最多重试 3 次 |
| 版本冲突 | 以版本号高的为准，保留冲突记录 |
| 大量未同步事件 | 分批推送，每批最多 100 条 |
| 重复事件 | 通过 eventId 去重 |
