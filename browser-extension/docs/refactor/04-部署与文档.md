## 详细说明

### 4.1 多架构 Docker 构建

当前 Dockerfile 仅构建 amd64。需要支持 arm64（Apple Silicon / 树莓派）：

```dockerfile
# 使用 buildx 多架构构建
FROM --platform=$BUILDPLATFORM golang:1.22-alpine AS builder
ARG TARGETARCH
# ...
```

构建命令：
```bash
docker buildx build --platform linux/amd64,linux/arm64 -t spidermemos/tab-sync-server:latest .
```

### 4.3 用户部署文档

`tab-sync-server/README.md` 需要扩展为完整的部署文档：

```markdown
# 部署指南

## 快速开始（Docker）

docker run -d -p 8080:8080 -v tab-sync-data:/app/data spidermemos/tab-sync-server

## 首次设置

1. 访问 http://localhost:8080/setup
2. 设置管理员密码
3. 保存生成的 Token

## 配置浏览器扩展

1. 打开扩展设置
2. 输入后端地址：http://localhost:8080
3. 输入 Token：粘贴步骤 3 中生成的 Token
4. 点击「验证连接」

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| PORT | 8080 | 服务端口 |
| DATA_DIR | ./data | 数据目录 |
| JWT_SECRET | (自动生成) | JWT 签名密钥 |
| MIN_EXT_VERSION | 1.0.0 | 最低扩展版本 |
| MAX_EXT_VERSION | 2.0.0 | 最高扩展版本 |

## 数据备份

SQLite 数据库文件位于 `./data/tab-sync.db`，直接备份此文件即可。
```

### 4.6 CI/CD

GitHub Actions 工作流：

```yaml
name: Build and Publish

on:
  push:
    tags: ['v*']

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: docker/setup-buildx-action@v3
      - uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - uses: docker/build-push-action@v5
        with:
          context: ./tab-sync-server
          platforms: linux/amd64,linux/arm64
          push: true
          tags: ghcr.io/spidermemos/tab-sync-server:latest
```
