## 详细说明

### 1.1 下载 Go 依赖

```bash
cd tab-sync-server
go mod tidy
```

这会下载所有依赖并生成 `go.sum`。

### 1.2 验证编译

```bash
go build ./cmd/server
```

确保无编译错误。

### 1.3 首次设置向导

当前 `SetupHandler.RenderSetupPage` 仅返回纯文本，需要实现一个嵌入式的 Web 管理界面：

- 使用 Go 的 `embed` 将 `web/` 目录嵌入二进制
- 设置向导页面：管理员设置密码 → 自动生成第一个 Token
- 管理后台页面：Token 管理（生成/吊销/列表）、系统统计

**关键文件**：
- `internal/handler/setup.go` - 需要完善
- `web/` 目录 - 需要创建（HTML + JS）

### 1.4 类型引用修正

检查 `internal/handler/device.go` 中 `deviceToMap` 函数，确认正确引用了 `model.Device` 类型。

### 1.5 配置持久化

当前 `config.Load()` 从环境变量读取配置。需要：
- 首次初始化后，将 JWT Secret 等配置写入数据库的 `server_configs` 表
- 后续启动时优先从数据库读取配置

### 1.6 日志系统

使用 Go 标准库 `log/slog` 或 `zerolog` 添加结构化日志：
- 请求日志（中间件）
- 错误日志（服务层）
- 启动日志

### 1.7 单元测试

为关键服务编写测试：
- `AuthService.VerifyToken` / `GenerateToken` / `RevokeToken`
- `DeviceService.Register`（幂等性）
- `WorkspaceService.Create` / `Update` / `MoveTab`

### 1.8 集成测试

使用 `httptest` 测试 API 端点：
- `GET /v1/tab-sync/version` 返回正确版本信息
- `POST /v1/tab-sync/auth/verify-token` Token 验证流程
- `POST /v1/tab-sync/devices/register` 设备注册流程
- 完整的 CRUD 工作组流程
