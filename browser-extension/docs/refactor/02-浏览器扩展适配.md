4. **保留**：`X-Device-Id` 附加逻辑

### 2.5 版本协商实现

在扩展启动时（`background/index.ts` 的 `onStartup` 或 `onInstalled`）：

```typescript
async function checkVersionCompatibility() {
  const baseUrl = await storage.get(STORAGE_KEYS.API_BASE_URL)
  if (!baseUrl) return // 未配置后端，跳过

  const res = await fetch(`${baseUrl}/v1/tab-sync/version`)
  const json = await res.json()
  const data = json.data

  if (res.status === 426) {
    // 扩展版本过高，需要升级后端
    showNotification('后端版本过旧，请升级 Docker 镜像')
    return
  }

  // 比较版本
  const extVersion = chrome.runtime.getManifest().version
  if (compareVersions(extVersion, data.min_ext_version) < 0) {
    showNotification('扩展版本过低，请升级浏览器扩展')
    return
  }

  // 保存版本信息
  await storage.set('server_version_info', data)
}
```
