## 技术决策速览

| 决策点 | 选择 | 原因 |
|--------|------|------|
| 轻量后端语言 | Go | 单文件编译部署、内嵌 SQLite、跨平台 |
| 数据库 | SQLite (glebarez/sqlite) | 纯 Go 实现、无需 CGO 也能编译（但当前用 CGO 版性能更好） |
| HTTP 框架 | Gin | 高性能、文档丰富、社区活跃 |
| ORM | GORM | 支持多数据源切换（只需改驱动和 DSN） |
| 认证方式 | Bearer Token（类似 API Key） | 简单、无需账号密码、适合私有部署 |
| API 响应格式 | CommonReturn（与织个网一致） | 扩展端无需大改，向后兼容 |
